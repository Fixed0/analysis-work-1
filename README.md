**Группа:** ОВКИПо-302

## 1\. Исходные данные

**Название программного продукта:** Visual Studio Code (VS Code)

**Класс программного обеспечения:** редактор исходного кода с поддержкой расширений.

**Заказчик:** начинающий разработчик, изучающий язык программирования Python.

**Цель анализа:** определить, насколько VS Code подходит начинающему разработчику для написания, запуска и отладки программ на Python с учётом удобства использования, функциональности и потребления ресурсов компьютера.

## 2\. Критерии анализа

|№|Критерий|Что именно оценивается|Как можно проверить|
|-|-|-|-|
|1|Удобство использования|Насколько просто найти и использовать основные функции редактора|Выполнить типовые действия: создать файл Python, сохранить его, открыть папку проекта и найти нужную команду; зафиксировать возникшие затруднения|
|2|Поддержка Python|Возможность редактировать и запускать Python-код с подсветкой синтаксиса и подсказками|Установить официальное расширение Python, открыть файл `.py`, проверить подсветку синтаксиса, подсказки и запуск программы|
|3|Отладка программ|Возможность находить ошибки с помощью точек останова и пошагового выполнения|Запустить тестовую программу в режиме отладки, поставить точку останова и проверить пошаговое выполнение и просмотр значений переменных|
|4|Производительность|Скорость запуска редактора и открытия проекта|Несколько раз запустить редактор и открыть одну и ту же папку проекта в одинаковых условиях; записать время выполнения|
|5|Потребление ресурсов|Объём используемой оперативной памяти и нагрузка на процессор при работе|Открыть проект с несколькими файлами, выполнить программу и посмотреть потребление памяти и процессора в диспетчере задач|
|6|Работа с расширениями|Возможность установить и использовать дополнительные инструменты для Python|Установить расширение Python и проверить, что оно доступно, включено и предоставляет заявленные функции в редакторе|

## 3\. Вывод

Выбранные критерии подходят для анализа VS Code, поскольку отражают основные задачи начинающего разработчика при изучении Python. Удобство использования важно, так как сложный интерфейс может затруднять освоение редактора. Поддержка Python и средства отладки имеют особое значение: они помогают писать, запускать и проверять программы, а также находить ошибки. Производительность и потребление ресурсов позволяют определить, насколько комфортно редактор работает на компьютере пользователя. Проверка расширений показывает, можно ли дополнить базовые возможности необходимыми инструментами. Поскольку каждый критерий связан с конкретными действиями или измерениями, результаты можно сравнивать в одинаковых условиях. Таким образом, предложенная система критериев позволяет получить обоснованное представление о пригодности VS Code для начинающего разработчика, хотя для более объективной оценки желательно повторить проверки и зафиксировать результаты.
